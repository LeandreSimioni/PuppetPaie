Nous vous recommandons le paiement de vos cotisations au moyen du
prélèvement SEPA
(Single Euro Payment Area) dans
votre DSN
(Déclaration Sociale Nominative).
Il repose sur le bloc de données « Versement organisme de protection sociale » (S21.G00.20). Le prélèvement SEPA simplifie et fiabilise les transactions vers chaque organisme de protection sociale.
Attention de bien compléter un bloc (S21.G00.20) par organisme destinataire de paiement.
Bon à savoir
Code Mode de paiement

05

Effectuer un paiement par organisme (Retraite / Prévoyance / Congés Spectacles) en utilisant les identifiants organismes de protection sociale suivants :
Pour la retraite Audiens > 44832375800038
Pour les Congés Spectacles > 77567608300030
Pour Audiens Santé Prévoyance > P0983
L’échéance de paiement pour Audiens est pour un mois M, le 25 du mois M+1. Cette date est automatiquement retenue pour les paiements retraite et Congés Spectacles mais doit être renseignée dans le bloc paiement à destination d’Audiens Santé Prévoyance (P0983).
En cas d’échéance trimestrielle (entreprises de – 11 salariés), la date à retenir pour chaque trimestre est le 25 du mois suivant le dernier mois du trimestre.
