Comprendre la structure du fichier d'import XImport

    RÉSUMÉ
    Cet article décrit la structure du fichier Ximport ainsi que la procédure d’export des écritures au format XImport dans Sage 50.



    Résolution
    Structure du fichier XImport
    Le fichier XIMPORT.TXT est un fichier de type sans délimiteur fixe (SDF). La taille d’un enregistrement ne dépasser 137 caractères.
    Le séparateur décimal est une virgule.
    Les données numériques sont alignées à droite, les autres données à gauche.
       ▼ Consultez la structure du fichier
                       Titre                     Nombre De Caractères                   Type
    N° de Mouvement                                      5 caractères    Numérique
    Journal                                              2 caractères    Alphanumérique
    Date d’écriture                                      8 caractères    Date (AAAAMMJJ)
    Date d’échéance                                      8 caractères    Date (AAAAMMJJ)

    Code analyt./budgét.                                 6 caractères    Alphanumérique
    Libellé du compte                                   34 caractères    Alphanumérique
    Euro                                                 1 caractère     Alphanumérique

    Procédure de génération d'un fichier au format XImport

    Étape 1 : Configuration de la préférence d'export au format Ximport

        1. Allez dans le menu Dossier > Options > Préférences.
   2. Déployez le dossier Liaison comptable.

   3. Double-cliquez sur Génération des écritures. La fenêtre Génération des écritures s'affiche.

   4. Dans l'onglet Destination du transfert, sélectionnez Fichier au format Ximport.

   5. Dans la zone Chemin d'accès, sélectionnez l'emplacement où enregistrer le fichier XImport.TXT .


             REMARQUE :
             Si le chemin est vide le fichier sera généré par défaut sur le bureau.



   6. Cliquez sur OK.



Étape 2 : Export des écritures

   1. Cliquez sur le menu Échanges > Exporter des écritures.

   2. Sélectionnez le format CIEL et cliquez sur OK.

   3. Sélectionnez la période souhaitée et le type d'écritures à exporter (validées, en brouillard, en simulation).

   4. Cliquez sur OK.

   5. Dans la fenêtre qui s'affiche, cliquez sur Continuer.

   6. Si l'option Voir les écritures avant transfert est cochée, la fenêtre Écritures à transférer s'affiche.

   7. Cliquez sur Continuer.


Le fichier des écritures comptables au format Ximport est généré.
