# PuppetPaie

- Les règles pour un agent qui travaille dans ce dépôt sont dans `atelier/AGENTS.md` : lis-le en entier avant toute action.
- La notice pour piloter le logiciel (le moteur, ses routes) est `logiciel/AGENTS.md`.

Le plus important, pour n'avoir pas à ouvrir ces fichiers : **on ne lit jamais `prive/config/coffre.bin`,
`prive/config/google-jeton.bin` ni `prive/config/maj-cle-privee.bin`**, et **un dépôt réel, un envoi ou une signature exige
le mot de passe du logiciel, tapé par un humain au moment de l'acte**.
